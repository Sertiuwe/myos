**myos** — это хобби-проект по созданию операционной системы с нуля для архитектуры x86_64. Проект разрабатывается в свободное время с целью изучения низкоуровневого программирования, архитектуры компьютера и принципов работы ядра.

Главная особенность проекта — полная независимость от готовых решений. Здесь не используются GRUB, Multiboot или другие сторонние загрузчики. Управление процессом загрузки полностью реализовано в собственном двухступенчатом загрузчике, написанном на ассемблере.

## Основные возможности

На данный момент в проекте реализованы следующие подсистемы:

* **Загрузка и инициализация:** Собственный загрузчик (boot.asm, stage2.asm), переход в Long Mode, инициализация базовых структур.
* **Управление памятью:** Парсинг карты памяти (memmap.c), управление физической памятью, базовый менеджер памяти (память.c).
* **Прерывания:** Настройка таблицы дескрипторов прерываний (IDT), контроллер прерываний (PIC), обработчики прерываний и исключений (isr_stubs.asm, irq.c).
* **Многозадачность:** Планировщик задач (sched.c), переключение контекста на ассемблере (sched_switch.asm), системные вызовы (syscall.c).
* **Драйверы устройств:** Драйвер ATA (жесткие диски), драйверы ввода (клавиатура kbd.c, мышь mouse.c), инициализация шины PCI (pci.c), таймеры (PIT, RTC).
* **Файловая система:** Собственная файловая система myfs (myfs.c), кэширование блочных устройств (bcache.c), утилита генерации образа (mkmyfs.py).
* **Графический интерфейс:** Собственный графический сервер (graphic_server.c), API для работы с графикой (graphic_api.c), отрисовка курсора.
* **Пользовательский режим:** Терминал (термин.c), командная оболочка (shell.c), системная библиотека (syslib.c).

## Структура проекта

Исходный код разделен на логические модули. В корне репозитория находятся файлы, отвечающие за конкретные подсистемы:

* Makefile — основной скрипт сборки.
* linker.ld — скрипт компоновщика, определяющий карту памяти ядра.
* kernel.c / kerno.h — точка входа в ядро и базовая инициализация.
* kstdlib.c, kstring.c, kstdio.c — реализация стандартных библиотек для ядра (без использования libc).
* kpanic.c / kassert.h — механизмы паники и утверждений (asserts) для отладки.
* asset.c / graphic_server.c — графическая подсистема.
* ata.c / bdev.c — работа с дисками и блочными устройствами.

## Требования для сборки

Для сборки проекта необходимы следующие инструменты:
* Кросс-компилятор для x86_64 (например, x86_64-elf-gcc).
* Ассемблер nasm.
* Утилита сборки make.
* Python 3 (для генерации образа файловой системы).

## Сборка и запуск

    # 1. Клонирование репозитория
    git clone https://github.com/Sertiuwe/myos.git
    cd myos

    # 2. Сборка проекта
    make

    # 3. Генерация образа файловой системы (если требуется)
    python3 mkmyfs.py

    # 4. Запуск в эмуляторе QEMU
    qemu-system-x86_64 -drive format=raw,file=build/myos.img

(Убедитесь, что имя файла образа совпадает с тем, что генерирует ваш Makefile).

Для очистки артефактов сборки используйте:
    make clean
