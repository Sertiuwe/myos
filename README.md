# myos

Хобби-проект по созданию минимальной работоспособной операционной системы для архитектуры x86_64. Проект разрабатывается с нуля на языках C и Assembly в свободное время.

Главная особенность проекта — полный контроль над процессом загрузки. Не используются готовые решения вроде GRUB или Multiboot. Написан собственный загрузчик, который выполняет инициализацию оборудования, настраивает процессор и передает управление ядру.

## Цели проекта
* Создание собственного загрузчика.
* Разработка ядра на C и Assembly.
* Реализация графического интерфейса.
* Внедрение файловой системы.
* Реализация многозадачности.

## Технологии
* C — основная логика ядра и системных вызовов.
* Assembly — загрузчик, инициализация процессора, обработчики прерываний и переключение контекста.
* Makefile — сборка проекта.
* Linker Script — управление распределением памяти.
* Python — вспомогательные скрипты.

## Структура файлов
* `Makefile` — основной скрипт сборки.
* `app_demo.c` / `app_demo.h` — демонстрационное пользовательское приложение.
* `asset.c` / `asset.h` — работа с графическими ресурсами.

## Сборка
Для сборки необходимы: компилятор C (GCC/Clang с поддержкой x86_64), `make`, `nasm` (или используемый ассемблер) и Python.

git clone https://github.com/Sertiuwe/myos.git
cd myos
make

Для очистки артефактов сборки:
make clean

## Запуск
Тестирование ОС рекомендуется проводить в эмуляторе QEMU. Запуск производится с raw-образа диска или ISO.

qemu-system-x86_64 -drive format=raw,file=build/myos.img
qemu-system-x86_64 -cdrom build/myos.iso

(Убедись, что имя файла образа совпадает с тем, что генерирует твой Makefile).

## Статус проекта
Проект находится в стадии активной разработки (WIP). Код нестабилен. Реализация графического интерфейса, файловой системы и многозадачности находится в процессе. Запуск на реальном физическом оборудовании не рекомендуется.
